**Tecnologias:** `Python` `Jupyter Notebook` `Machine Learning` `Data Analysis`

O projeto apresenta uma redução simulada da taxa de churn de **56% para 18%**.

**Tecnologias:** `Python` `Jupyter Notebook` `Pandas` `Data Analysis`
